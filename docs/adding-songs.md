# 曲の追加手順

## 曲を置くフォルダ

```
ICEMANIA Dropbox\★日本アイスマニア協会\a_アイスの歌\AI-SONG\w_wav\ICE CREAM MUSIC BOX
```

このフォルダにある WAV が、そのままアプリの曲になります。
（2026-11 に旧名「b_BGM京都2026」から改名）

フォルダを移動・改名したときは、`src/lib/audioDir.mjs` の1か所だけ書き換えてください。

## 追加の流れ

1. **WAV を入れる**
   - ファイル名は `曲名.wav` か `曲名(v5.5).wav` の形にする
   - `(v5)` `(Remastered_v5.5)` などは表示名から自動で外れる
2. **確認する**（任意）
   ```bash
   node scripts/check-folder.mjs
   ```
   新しく入れた曲に 🆕 が付きます。
3. **表示名・ジャンルを決める**（任意）
   同じフォルダの `tracks-meta.json` に書く。書かなければファイル名から自動で付く。
4. **本番に反映する**
   ```bash
   npm run sync-r2
   ```
   WAV を MP3 に変換して R2 にアップロードし、曲一覧（tracks.json）を更新します。
   サイトへの反映は最大1時間ほどかかります（キャッシュのため）。

## 差し替え・非表示

- 新しいバージョンに差し替えたときは、古い WAV を `scripts/sync-to-r2.mjs` の `EXCLUDED_FILES` に入れると一覧から消える
- 先頭に固定したい曲は同じファイルの `PINNED_TRACKS` に入れる

## 歌詞（任意）

LRC ファイルを R2 の `lyrics/` に、音声と同じ名前（拡張子だけ `.lrc`）で置くと歌詞ボタンが有効になります。
